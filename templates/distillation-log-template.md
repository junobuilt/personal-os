## How to Use This File

1. **At session close,** during debrief, identify what was stumbled into.
2. **Write the entry** following the format. Be specific — abstract entries don't teach.
3. **Update the target file** with the encoded rule (project-instructions.md, anti-patterns.md, knowledge-base.md, or one of the universal files in personal-os).
4. **Commit both files** to GitHub so the change is permanent.

The discipline: every entry must produce an actual file update. Verbal lessons that don't get encoded disappear.
